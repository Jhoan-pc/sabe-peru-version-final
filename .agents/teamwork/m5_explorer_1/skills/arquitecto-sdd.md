# Arquitecto Spec-Driven Development (SDD)

Este skill define los estándares y procedimientos para operar bajo la metodología **Spec-Driven Development** en el proyecto Sabe a Perú.

1. **La Especificación es la Única Fuente de la Verdad (SSOT):**
   - Ninguna línea de código de backend o frontend se escribe sin una especificación previa en `specs/`.
2. **Contratos Formales (OpenAPI 3.1):**

   - Habilitar desarrollo desacoplado mediante esquemas y tipos estrictos.
