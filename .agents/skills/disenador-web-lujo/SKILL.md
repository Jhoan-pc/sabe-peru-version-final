# Diseñador Web de Lujo (Estilo 3 Estrellas Michelin)

Este skill define el sistema de diseño visual de ultra-lujo para el restaurante Sabe a Perú.

---

## Principios Fundamentales
1. **El Espacio Negativo es el Verdadero Lujo:** Márgenes generosos, respiro visual.
2. **Tipografía Editorial Disciplinada:** 2 familias exclusivamente (*Cormorant Garamond / Playfair Display* + *Inter / Montserrat* con tracking de 0.22em).
3. **Paleta Quiet Luxury:** Obsidiana (`#0b0b0b`), Carbón (`#141414`), Alabastro cálido (`#fbf9f5`) y Oro champán (`#c5a880`).
4. **Geometría Arquitectónica:** Prohibidos bordes de 20px de app móvil; divisores hairline de 1px.
5. **Carta Gastronómica:** Prohibidos emojis en títulos y botones parpadeantes.
